### 01:12 @unknown

全球首个基于 Subquadratic Sparse Attention (SSA) 架构的前沿 LLM ~「SubQ」，实现 12M token 的实用上下文窗口，同时在效率上大幅领先传统 Transformer，来自 @subquadratic   技术核心突破：SSA 机制 传统 Transformer 的标准注意力是全对全（all-pairs），计算复杂度为 O(n²)，导致长上下文成本爆炸。大多数 token 间的交互实际无意义，却仍需全量计算。  SSA 的创新在于内容依赖的选择（content-dependent selection）： · 每个 query 只动态挑选真正相关的 key 位置进行注意力计算。 · 实现线性缩放（linear scaling）：计算与内存成本随序列长度线性增长，而非二次方。 · 同时保留内容驱动路由与任意位置精确检索能力，避免了固定模式稀疏注意力（位置无关）、RNN/SSM（状态压缩丢失细节）或 DeepSeek DSA（selector 仍为二次方）等方案的权衡。  实测效果（B200 GPU + FlashAttention-2 对比）： · 128K token：7.2× 预填充加速 · 1M token：52.2× 加速 · 成本 < Opus 的 5%，支持 12M token 上下文。  训练与功能定位 SubQ 采用三阶段训练（预训练 → SFT → RL），特别强化长上下文下的可靠检索与多跳推理，针对企业真实场景（如完整代码库、长合同、跨文档研究）优化，而非仅追求基准分。  功能定位：解决“名义上下文窗口”（能塞多少 token） vs “功能上下文窗口”（能有效利用多少 token）的鸿沟。适用于 Coding Agent、长期 Agent 会话、企业知识库等需要“一次性看全”而非 RAG/分块的场景。  SubQ Code 也可以申请试用，我也刚刚申请，期待通过后再做具体分享。申请链接在这： https://t.co/RsJ5DfoOsF

**斯坦福这场2小时讲座的核心内容总结**（演讲者为斯坦福讲师，主要讲解大语言模型LLM的底层技术逻辑）：  演讲者用非常硬核、系统的方式，把ChatGPT、Claude等主流大模型的“底层核心逻辑”彻底拆解，重点围绕**训练目标、Tokenizer、评估方法、数据**四个核心模块展开，全程干货密集，几乎没有废话。  ### 1. **核心训练机制（Loss函数）** - LLM的本质是**下一个token预测**（next token prediction）。 - 使用**交叉熵损失（cross-entropy loss）**来训练，目标是**最大化文本的似然度（likelihood）**。 - 简单说：模型每一步都在学习“给定前面内容，下一个最可能的词是什么”，通过不断最小化损失来实现。  ### 2. **Tokenizer（分词器）** - 为什么不用单词或字符直接分？因为**token要更通用、更高效**。 - 主流方法是**Byte Pair Encoding (BPE)**：   - 从大语料开始，先每个字符一个token；   - 反复合并出现频率最高的相邻token对，形成常见子序列作为最终token。 - 这能很好处理代码、罕见词、多语言等问题。  ### 3. **LLM评估方法** - 不是单一指标，而是**聚合多种自动可评估的基准**（aggregate standard NLP benchmarks）。 - 典型代表：   - HELM（Holistic Evaluation of Language Models）：全面评估语言模型。   - Hugging Face LLM Leaderboard：公开排行榜。 - 演讲者强调：评估方式有很多种，需要综合看待模型真实能力。  ### 4. **数据（Data）——全场最重点、最“封神”的部分** - **数据是你系统的最终来源（ultimate source of the System）**。 - 实际构建LLM时，**数据收集和处理占了最大比重，是真正的关键**。 - 需要深入研究的痛点：   - 如何高效、干净地处理海量数据？   - 如何平衡不同领域（domain）的数据分布？   - 合成数据（synthetic data）和多模态数据的利用。 - 行业现状：**高度保密**（secrecy），因为涉及竞争动态和版权责任。 - 常见公开学术数据集举例：   - C4（约150B tokens）   - The Pile（约280B tokens）   - Dolma（3T tokens）   - FineWeb 等  演讲者反复强调：**数据质量和处理方式决定了模型的上限**，很多前沿研究和工业秘密都藏在这里，连AI圈内很多老从业者平时都接触不到这些细节。  ### 演讲者的主要建议（隐含在讲解中） - **别再碎片化刷短视频了**，沉下心把底层原理搞透，才能真正“颠覆认知”。 - 想做AI、训练或改进模型，**必须把精力重点放在数据上**——这是目前最有研究价值、最能拉开差距的方向。 - 行业里还有大量开放问题（数据处理效率、合成数据、领域平衡等），值得深入钻研，而不是只停留在调用API的表面应用。 - 建议大家系统学习这些硬核知识，而不是只看热闹。  总的来说，这场讲座把大模型的“黑箱”几乎扒光了，含金量极高。演讲者不是在卖课，而是在**把真正决定模型成败的底层逻辑讲透**，特别适合想深度理解AI而不是浅层使用的人。  看完两小时，基本能对ChatGPT/Claude这类模型“为什么这么强、瓶颈在哪里”有清晰认知——这正是原帖推荐的理由。强烈建议抽完整时间一口气看完！
