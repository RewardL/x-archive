This has been possible for months and barely anyone is doing it  Months ago, Andrej Karpathy, a co-founder of OpenAI, open-sourced a project that gets you the best possible answers instead of trusting one model on its own. It's called LLM Council.  Repo: /karpathy/llm-council  The idea in two lines: your question goes to several models at once, Claude, GPT, Gemini, whatever you pick.   They answer independently, then anonymously critique and rank each other (anonymous so they can't play favorites), and a chairman model merges the best of all of it into one final answer. One model just agrees with you; a council catches each other's mistakes.  How to set it up:  > Clone the repo  > It uses uv for setup, install dependencies with uv sync  > Get an OpenRouter API key and add it, this is what lets one app reach Claude, GPT, and Gemini together  > Pick which models sit on your council in the config, then run it. It opens as a local web app, like ChatGPT but with a whole panel answering  Bookmark this
