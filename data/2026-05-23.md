5 patterns for building long-running AI Agents  1. Checkpoint-and-Resume → Save progress in batches (like every 50 documents) so the agent can recover from failures without restarting entire workflows  2. Delegated approval → Long-running agents can “freeze” mid-process, preserve full context, and resume instantly once a human responds – even 24 hours later  3. Memory-layered context → Agents need separate working and long-term memory plus strict governance (identities, registries, access policies) to avoid memory drift and data leakage  4. Ambient processing → Don’t hardcode policies into agents – let background agents react to events in real time while pulling rules from a centralized governance layer  5. Fleet orchestration  5. Fleet orchestration for AI agents → Use a coordinator to orchestrate specialist agents, allowing components to run, scale and evolve independently. This prevents failures in one agent from cascading to others  Here's a full practical guide, including A2A and MCP interoperability → https://t.co/d7O5OTTnJJ by @addyosmani (Director at @GoogleCloud) and @Saboo_Shubham_ (Senior AI Product Manager at @google)
