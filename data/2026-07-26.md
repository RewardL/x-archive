Here's how we can progressively build from supervised training to RL, agentic RL, and finally a unified RL + world modeling objective…  Each of the steps mentioned above is outlined in greater detail below. An implementation of each step in PyTorch is provided in the attached images for reference.  Supervised training teaches an LLM to predict the next token in a sequence using a cross entropy loss. The supervision comes directly from the training data (i.e., the ground truth next token is already present in every example). During training, we maximize the likelihood of these ground-truth tokens. This same objective is used for both pretraining and supervised finetuning (SFT).  Reinforcement learning (RL) trains an LLM on its own generations (i.e., on-policy learning) instead of ground-truth / supervised text. The model first samples completions, receives a reward for each rollout (from a verifier or reward model), and then updates its policy to increase the probability of high-reward outputs using some policy gradient algorithm. More specifically, Policy gradient algorithms—like PPO or GRPO—implement this by weighting each generated token according to its advantage, encouraging behaviors that lead to better outcomes.  Agentic RL extends this same idea from single-step LLMs to multi-step agents. Rather than producing output in a single step, the model repeatedly generates actions, invokes tools, and receives observations from its environment over many interaction steps (i.e., within an agentic loop). The learning objective of agentic RL remains largely unchanged relative to standard RL: we simply compute the RL loss over the agent-generated action tokens while masking out environment observations (or other tokens that are not generated by the LLM). Besides such action masking, the implementation remains the same relative to standard RL.  Agentic world modeling combines supervised learning and (agentic) RL into a single objective. LLM-generated action tokens are optimized with an advantage-weighted RL loss, while observation tokens receive a constant positive weight that reduces to supervised next-token prediction. This hybrid objective simultaneously teaches the model what actions to take and how its environment responds, allowing the agent to improve both decision making and its internal simulation of the world. This is a hybrid agent and world model!
