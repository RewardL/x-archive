### 16:15 @unknown

Does world modeling improve coding agents? The answer seems to be yes...  Code world models. A coding agent is somewhat similar to an embodied agent. The world for a coding agent is not the physical world, but rather the harness in which it exists, such as a terminal environment. This environment changes as the coding agent makes tool calls, such as modifying files or running code. The feedback returned by these tool calls is only a lossy representation of the environment in which the coding agent exists.  Training a world model. How is world modeling defined in the context of a coding agent? The key idea is to expand agentic RL by augmenting the core policy update with an SFT-style loss that is applied only to environment or tool-output tokens. This way, the coding agent can be trained to predict environment feedback and learn the consequences of its actions.  Concrete objective. More specifically, we can expand the core RL objective with an additional cross-entropy loss term. These two terms are added together as a weighted sum, where the cross-entropy loss is weighted much lower than the core policy update. Similar to a standard agentic RL setup, we apply the core policy update to agent-generated or LLM-generated tokens. The cross-entropy loss, which we can call the environment loss, is applied only to environment feedback, meaning tool-call outputs.  Notably, this type of auxiliary loss can be computed easily because we already have the log probabilities for all tokens in a rollout when computing the core RL update. The only additional work required is taking an additional masked sum over environment tokens to compute the environment loss.  Benefits of world modeling. The idea of including the cross-entropy objective in agentic RL is based on the following intuition:  Tool outputs are a partial representation of the actual environment or container state. The environment loss teaches the coding agent to accurately predict these tool outputs. Because the coding agent can predict these outputs, it should better understand the dynamics of the environment and how its actions affect that environment.  Does this actually work? Papers like ECHO (https://t.co/akClpFhX4M) show that including the environment loss in agentic RL can improve the agent. The agent learns noticeably faster and tends to achieve better final performance, especially in more complex or realistic environments with non-trivial dynamics.  One very interesting observation in ECHO is that agents trained with the extra environment loss tend to use inference compute more efficiently. While improving performance, these agents use fewer output tokens, environment turns, and tool calls.   This finding seems to indicate that an improved understanding of the environment and the consequences of tool calls enables agents to solve problems more cleanly and efficiently.
