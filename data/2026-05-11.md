"Demystifying Manifold Constraints in LLM Pre-training"  LLM pre-training depends on a stack of heuristic tricks, eg. normalization layers, weight decay, and optimizer tuning.  This paper suggests that by constraining weight matrices to geometric manifolds like spectral or Frobenius spheres reduces most of these heuristics.   They introduced this optimizer called MACRO, which is a single-loop Riemannian method with provable convergence that keeps weights on-manifold every step.  Manifold constraints bound activation scales, replacing learnable RMSNorm. Muon diverges without it but MACRO doesn't. They also lock the relative learning rate from step one, replacing weight decay entirely as ablations show it has zero effect.   On QWEN3-like models up to 1B, MACRO matches or edges out MuonH while maintaining strict geometric guarantees.

HOW AGENTIC AI PERCEIVES ITS ENVIRONMENT  Agentic AI systems do more than respond to prompts. They continuously observe, interpret, and understand their environment so they can make intelligent decisions and take meaningful actions.  Here’s the flow:  Input Collection: The agent receives information from multiple sources such as user prompts, APIs, sensors, databases, applications, files, websites, or real-time streams.  Signal Processing: Raw input data is cleaned, structured, and transformed into formats the agent can understand. This may include text parsing, image recognition, audio transcription, or data normalization.  Context Awareness: The agent identifies relevant details from the environment, including user intent, system state, ongoing tasks, previous interactions, and operational constraints.  State Tracking: The system continuously monitors changes in its environment. It tracks updates, completed actions, errors, and evolving conditions in real time.  Memory Retrieval: The agent accesses short-term and long-term memory to connect current observations with previous experiences, stored knowledge, and historical interactions.  Pattern Recognition: Machine learning models and reasoning systems identify patterns, anomalies, trends, and relationships within the collected information.  Environment Modeling: The agent builds an internal representation of its environment. This model helps it understand how different entities, systems, and actions are connected.  Priority Detection: The agent determines which signals require immediate attention and which information is less important. Critical events are prioritized for faster response.  Reasoning and Interpretation: The AI analyzes environmental data to understand what is happening, why it matters, and what actions may produce the best outcomes.  Feedback Integration: The agent continuously learns from feedback, outcomes, and new observations. This allows it to adapt to changing environments over time.  Decision Preparation: Once the environment is understood, the agent prepares strategies, selects tools, and determines the next actions required to achieve its objective.  Adaptive Awareness: Advanced agentic AI systems dynamically update their perception as new information arrives, enabling autonomous behavior in unpredictable environments.
